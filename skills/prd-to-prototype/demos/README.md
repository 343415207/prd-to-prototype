# 原型 Demo 模板

prd-to-prototype 技能的两个参考示例，可直接复制结构生成新原型。

| Demo | 类型 | 说明 |
|------|------|------|
| [h5-clothing-mall](./h5-clothing-mall/) | H5 移动端 | 服装商城：TabBar、商品列表、详情、购物车、我的 |
| [pc-operations-system](./pc-operations-system/) | PC 后台 | 运营管理系统：数据概览、订单/用户/商品管理、设置 |

## 使用

```bash
cd h5-clothing-mall   # 或 pc-operations-system
npm install
npm run build
# 打开 dist/index.html
```
